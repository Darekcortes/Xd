# 🎰 Casino de la Suerte

Juego de pura suerte en un solo archivo (`index.html`). Ábrelo en el navegador y a jugar.

- **Tragamonedas**: 3 rodillos, parejas y tríos, jackpot 💎💎💎 x1000 y modo auto.
- **Ruleta**: rojo/negro x2, verde x14.
- **Raspa y Gana** (nivel 2): raspa con el dedo/ratón, líneas de 3 símbolos.
- **Mayor o Menor** con dados (nivel 3).
- **Cofres Misteriosos** (nivel 4): elige uno de tres… o calavera.
- **Racha** de victorias que multiplica premios, **amuletos** que suben tu suerte,
  niveles, logros, regalo diario y préstamo de rescate.

El progreso se guarda en el navegador. Monedas ficticias, sin dinero real.
